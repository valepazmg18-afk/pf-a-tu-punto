# Listado de dependencias – A Tu Punto

## 1. Frontend

| Dependencia | Descripción |
|---|---|
| React | Biblioteca para construir la interfaz de usuario. |
| Vite | Herramienta para crear y ejecutar el proyecto frontend. |
| React Router DOM | Permite gestionar la navegación entre las distintas vistas. |
| CSS | Permite definir los estilos y la apariencia de la aplicación. |

## 2. Backend

| Dependencia | Descripción |
|---|---|
| Node.js | Entorno de ejecución de JavaScript en el servidor. |
| Express | Framework para crear la API REST. |
| pg | Permite conectar el backend con PostgreSQL. |
| cors | Permite configurar las solicitudes entre frontend y backend. |
| dotenv | Permite gestionar variables de entorno. |
| bcrypt | Permite proteger las contraseñas de los usuarios mediante hash. |
| jsonwebtoken | Permite gestionar la autenticación mediante tokens JWT. |

## 3. Base de datos

| Tecnología | Descripción |
|---|---|
| PostgreSQL | Sistema de gestión de base de datos relacional para almacenar usuarios, productos, categorías y carritos de compra. |

## 4. Herramientas de desarrollo

| Herramienta | Descripción |
|---|---|
| Visual Studio Code | Editor de código para desarrollar la aplicación. |
| Git y GitHub | Permiten controlar versiones y almacenar el código fuente. |
| Postman | Permite probar los endpoints de la API REST. |
