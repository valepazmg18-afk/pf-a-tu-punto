# 🧶 A Tu Punto

**A Tu Punto** es una tienda online de productos tejidos a crochet, donde los usuarios pueden explorar productos, registrarse, iniciar sesión y realizar compras mediante un carrito de compras.

## 🚀 Proyecto desplegado

🔗 **Aplicación en producción:** https://pf-a-tu-punto-hito2.onrender.com

## 🛠️ Tecnologías utilizadas

### Frontend
- React
- Vite
- React Router DOM
- Bootstrap
- Lucide React

### Backend
- Node.js
- Express
- PostgreSQL
- JWT para autenticación

### Despliegue
- Render (frontend, backend y base de datos)

## ✨ Funcionalidades

- Registro de usuarios.
- Inicio y cierre de sesión.
- Autenticación mediante token JWT.
- Visualización de productos.
- Carrito de compras.
- Modificación de información del perfil.
- Persistencia de los datos.
- Acceso según el rol del usuario: cliente y administrador.

## 👥 Roles

- **Cliente:** puede acceder a las funcionalidades de usuario de la tienda.
- **Administrador:** cuenta con acceso a las funcionalidades de administración.

## 💻 Ejecución local

Para ejecutar el proyecto localmente, es necesario contar con Node.js y PostgreSQL instalados, además de configurar las variables de entorno necesarias.

### Frontend

```bash
cd HITO2
npm install
npm run dev
```

### Backend

Ingresar a la carpeta del backend, instalar las dependencias y configurar las variables de entorno para la conexión a la base de datos.
